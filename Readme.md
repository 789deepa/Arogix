# 🏥 Arogix

Arogix is a full-stack healthcare platform designed to improve access to medical services for people in rural areas. It enables patients to connect with doctors online, reserve medicines from nearby pharmacists, and receive digital prescriptions—reducing unnecessary travel and making healthcare more accessible.

## ✨ Features

### 👨‍⚕️ Patient
- Secure login and registration
- Search and connect with available doctors
- Real-time consultation requests
- Join video consultations
- Receive digital prescriptions
- Upload and share lab reports
- Reserve medicines from pharmacies
- Manage appointments and medical records

### 🩺 Doctor
- Manage appointment requests
- Conduct online consultations
- Generate and share digital prescriptions
- Review patient reports
- Track consultation history

### 💊 Pharmacist
- View medicine reservations
- Manage medicine availability
- Process patient orders efficiently

### 📹 Real-Time Communication
- Instant consultation notifications
- Video consultation using Jitsi Meet
- Socket.IO-powered real-time communication

### 🤖 Smart Healthcare Features
- AI-powered first-aid assistance
- Lab report management
- Digital healthcare records

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/789deepa/Arogix.git
cd Arogix
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Run the Socket.IO server

```bash
npx ts-node src/server/server.ts
```
